# Kai Content Agent

Kai 的本地短视频生产工具。计划支持两条生产线。A 线处理已授权访谈素材并制作解读短视频。B 线制作原创 AI 科技、商业认知、个人成长和生产力、工具实测与技术项目内容。两条生产线共享媒体处理、字幕、品牌模板、质量审核和导出，后续支持抖音与小红书。

## 当前使用

P0 已建立本地工程骨架。生产命令随对应阶段的实现一并记录。打开项目根目录后，先读 [项目规则](AGENTS.md) 和 [当前状态](STATUS.md)。可在 PowerShell 用 `git status --short --branch` 查看本地检查点，用 `ffmpeg -version` 和 `ffprobe -version` 查看媒体工具。

| 目录 | 用途 |
| --- | --- |
| `inbox/` | 原始输入与素材授权记录 |
| `workspace/` | 按任务存放中间产物与结构化交接文件 |
| `output/` | 最终视频与配套成品 |

这些目录已在本机创建，属于本地运行数据目录。Git 不记录目录本身。若从提交恢复，按需重建即可。
